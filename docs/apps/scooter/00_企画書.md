# スクーター管理 企画書

## 目的

Uber配達で利用する複数台のスクーターについて、業務乗車・降車時のODOを記録し、年度別の総走行距離から業務利用割合と私用割合を確認する。現在のレンタル車両と将来の購入車両を独立して管理する。

## 機能

- 車種・ナンバーを表示するカード一覧。有効な車両を先に、無効な車両を灰色で後ろに表示する。
- 車両情報の購入／レンタル切り替え。それぞれの入力値は切り替え後も保持する。
- 車両写真を端末から選択し、アプリ内に保存する。未登録時は共通スクーター表示。
- 業務乗車・降車の日時、ODO、メモを記録。乗車中でも保存でき、アプリ再起動後に降車を記録できる。
- 年度別の年始・利用開始時と、最終・集計時点のODOと日付を記録する。
- 給油（日付・ODO・量・金額・メモ）と整備（日付・ODO・内容・金額）を記録する。
- ダッシュボードで業務／私用割合、走行距離、月別業務距離、給油・整備費を表示する。

## UI

共通の紫色ヘッダーとメニューを使用する。ホームとドロワーに入口を追加する。

車両詳細は「ダッシュボード」「車両情報」「給油情報」「整備情報」の順に配置し、初期表示はダッシュボード。タップと左右スワイプで移動する。右下の＋から乗車／降車・給油・整備・基準ODO・車両情報の登録・編集画面を開く。各履歴をタップすると編集・削除できる。

## 保存と対象外

SQLiteとアプリ専用の写真領域だけに保存する。ログイン、外部へのデータ送信、クラウド同期、自動運転検知、Uber連携は追加しない。購入費・レンタル料は車両情報として保持し、費用グラフ・費用合計は登録した給油と整備のみを対象とする。税額や減価償却の計算は行わない。

## 完了条件

複数車両の記録が混ざらないこと。再起動後に履歴・乗車中の記録・写真を復元できること。基準ODOと完了した業務走行から割合を計算し、矛盾や未入力がある場合は割合を表示せず修正方法を案内すること。既存機能のテーブルを変更しないこと。
