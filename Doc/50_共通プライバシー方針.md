## 1. 基本方針

個人用アプリとして、必要最小限のデータだけを扱う。機能の実装前に、保存場所、通信の有無、削除方法を定義する。

## 2. 初期方針

- 端末内で完結できる機能は端末内で処理する
- 不要なログイン、広告、アクセス解析を先行導入しない
- Firebaseを利用する場合は、利用機能ごとに目的とデータ範囲を明記する
- Firebase App Distributionで扱われる配布情報と、アプリ内データを区別する

## 3. 機能追加時の確認

- 取得する情報
- 保存場所
- 保存期間
- 外部送信の有無
- 利用者による削除方法
- Firebase Security Rulesの範囲

## 4. 未決事項

- アプリの正式なデータ取扱い
- Firebaseサービスの利用範囲
- 公開時のプライバシーポリシー掲載方法
