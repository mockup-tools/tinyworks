## 1. 開発環境の方針

`uraregi`と同様に、ローカル環境へAndroid開発環境を個別に構築することを必須にせず、GitHub Codespacesを正とする。リポジトリ直下の`.devcontainer`で開発環境を固定する。

## 2. 固定するもの

- JDK 17
- Android SDK Command-line Tools
- Android SDK API 37
- Android SDK Build Tools 37.0.0
- Gradle Wrapper
- Kotlin・Android Gradle Plugin・Composeなどの依存バージョン

Gradle Wrapperと依存バージョンはAndroidプロジェクトへ固定して含める。

## 3. Codespacesの作成

1. GitHubでリポジトリを開く。
2. **Code → Codespaces → Create codespace on main**を選ぶ。
3. `.devcontainer`からコンテナを作成する。
4. ターミナルでJDK、Android SDK、Gradle Wrapperを確認する。

```text
java -version
sdkmanager --version
cd pgm/tinyworks
./gradlew --version
```

## 4. プロジェクトルート

Gradleプロジェクトのルートは次の場所とする。

```text
pgm/tinyworks
```

## 5. 初期確認

アプリ実装後、少なくとも次の確認を行う。

```text
./gradlew testDebugUnitTest
./gradlew lintDebug
./gradlew assembleDebug
```

## 6. CIとの関係

GitHub Actionsでは、Codespacesと同じくJDK 17、Android SDK API 37、Build Tools 37.0.0を使用する。Androidプロジェクトを追加するまで、CIは構成確認だけを行う。
